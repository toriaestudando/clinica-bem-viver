# Clínica Bem Viver — protótipo PWA

### Cuidado, acolhimento e saúde em cada etapa da vida 💙

Este projeto consiste no desenvolvimento de um site fictício para uma clínica médica, criado com o objetivo de praticar e aprimorar conhecimentos em desenvolvimento web.

## ✨ Funcionalidades
- Apresentação da clínica e dos serviços.
- Formulário demonstrativo de solicitação de consultas.
- Layout responsivo para computadores e celulares.
- Identidade visual moderna e acolhedora.
- Estrutura inicial de PWA.

## 🛠️ Tecnologias utilizadas
- HTML5
- CSS3
- JavaScript

## 🎯 Objetivo
Praticar conceitos de programação, design de interfaces e responsividade, explorando a criação de um site institucional.

## ⚠️ Aviso
Este projeto é **exclusivamente educacional**, desenvolvido para fins de estudo e prática. A clínica é fictícia e as funcionalidades são demonstrativas, não devendo ser utilizadas para atendimentos médicos reais ou armazenamento de dados de pacientes.
